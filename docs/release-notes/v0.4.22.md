### 其他改动

- 新增提交准入策略检查（`.github/submission-policy.json`、`submission-policy.yml` 及对应测试）与 2026-11-24 登记轮 Agent Note。
- 索引条目由 147 条增至 151 条；版本 0.4.21 对齐到 0.4.22。

### Other changes
