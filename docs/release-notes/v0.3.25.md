> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。相对 npm 上现存的 0.3.24，索引从 85 条扩充到 119 条：新增 34 个条目，没有移除任何条目。索引仍是唯一数据源，工坊的插件清单与 `dsh-market.com` 的插件 manifest 都由它派生。

### 新功能

- 独立仓库：社区索引单独维护，登记 PR 在本仓库单独评审与合入
- 索引新增 34 个条目（85 → 119），包括 `dsh-autotier`、`dsh-background-agents`、`dsh-budget`、`dsh-checkpoint-rewind`、`dsh-local-ai`、`dsh-lsp-actions`、`dsh-memento`、`dsh-plugin-kit`、`dsh-session-sync`、`dsh-team-rooms`、`dsh-test-drive` 等

### 其他改动

- 新增 CI 与 tag 触发的发布管线

First standalone release after the community plugin index moved out of the dsh-web monorepo. The package name `@linxin666/dsh-client-ui-community-plugins` and the install path are unchanged; the version line advances on its own from here.

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field, or profile format is renamed. Relative to the 0.3.24 currently on npm the index grows from 85 entries to 119: 34 entries added and none removed. The index is still the single source of truth, and both the Workshop plugin list and the `dsh-market.com` plugin manifest derive from it.

### New Features

- Standalone repository: the index is maintained here and registration pull requests are reviewed and merged here
- 34 new index entries (85 to 119), including `dsh-autotier`, `dsh-background-agents`, `dsh-budget`, `dsh-checkpoint-rewind`, `dsh-local-ai`, `dsh-lsp-actions`, `dsh-memento`, `dsh-plugin-kit`, `dsh-session-sync`, `dsh-team-rooms` and `dsh-test-drive`

### Other Changes

- A listing icon for the plugin (`icon.svg`)
- Add CI and a tag-triggered release pipeline
- Add CONTRIBUTING and repository metadata
