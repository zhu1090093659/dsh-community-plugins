社区插件索引随 dsh-web 家族对齐到统一版本 0.4.20，并收录六个新社区插件。

> **兼容性**：没有破坏性变更；`dsh.engines.dsh`、peer 与 engines 下限、包名、导出面、持久化标识与线协议均未改，0.4.19 可直接升上来，也可直接退回，不需要迁移数据。

### 新功能

- 收录社区插件：`dsh-engramory`（Engramory 长期记忆）、`dsh-ai-diagrams`（AI 图表）、`dsh-braingames`、`bloomtutor-dsh`（BloomTutor 学习导师）、`travel-agent`（旅行模式 Travel Story）、`rss-pal-dsh`（RSS Pal）。

### 其他改动

- 补充 session-chains 默认折叠的商店文案说明；新增数轮收录与过期 PR 关闭的 Agent Note；版本 0.4.19 对齐到 0.4.20。

The community plugin index aligns to the unified family version 0.4.20 and lists six new community plugins.

> **Compatibility**: no breaking changes; the `dsh.engines.dsh` floor, peers, engines, package name, export surface, persisted identifiers and wire protocol are untouched. Upgrading from or rolling back to 0.4.19 needs no data migration.

### New features

- New community plugins: `dsh-engramory`, `dsh-ai-diagrams`, `dsh-braingames`, `bloomtutor-dsh`, `travel-agent` (Travel Story mode) and `rss-pal-dsh` (RSS Pal).

### Other changes

- Store copy now documents the session-chains fold default; Agent Notes for the registration rounds and stale-PR closes added; version 0.4.19 to 0.4.20.
