The community plugin index aligns to the dsh-web family's unified version. From this release on, the four satellite repositories publish the same X.Y.Z as this repository, satellites first; the jump from 0.3.25 to 0.4.2 is that alignment.

> **Important change**: no manual migration is needed, no persisted identifier, wire-protocol field, or profile format is renamed, and no index entry is added or removed. The package name `@linxin666/dsh-client-ui-community-plugins` and the install path are unchanged. The index is still the single source of truth, and both the Workshop plugin list and the `dsh-market.com` plugin manifest derive from it.

### Other Changes

- CI: pull requests are routed to their reviewers automatically, and the release pipeline can complete a tag that already published
- Text files check out with LF line endings
