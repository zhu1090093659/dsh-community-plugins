社区插件索引随 dsh-web 家族对齐到统一版本。本版本新增六个索引条目，并带上挂载重放修复。

> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。包名 `@linxin666/dsh-client-ui-community-plugins` 与安装方式不变。索引仍是唯一数据源，工坊的插件清单与 `dsh-market.com` 的插件 manifest 都由它派生。

### 新功能

- 新增六个社区插件条目：`dsh-session-suspend`（会话挂起提醒）、`dsh-ltm`（本地长期记忆）、`dsh-attention-health`（上下文健康）、`dsh-wx-bridge`（微信接入 DSH）、`agent-body`（器官化插件层）、`dsh-model-priority`（模型顺序）

### 修复

- 上一次挂载尚未释放时被拒绝的挂载不再丢失：持有者退出后自动重放，插件不会停留在未挂载状态

### 其他改动

- README：展示工坊上最受欢迎的三个社区插件
- AGENTS.md：补记索引条目的评审与合并规则

The community plugin index publishes on the family's aligned version. This release adds six index entries and carries the mount replay fix.

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field or profile format was renamed. The package name `@linxin666/dsh-client-ui-community-plugins` and its install path are unchanged. The index stays the single data source: the Workshop plugin list and the `dsh-market.com` plugin manifest are both derived from it.

### New Features

- Six new community plugin entries: `dsh-session-suspend`, `dsh-ltm`, `dsh-attention-health`, `dsh-wx-bridge`, `agent-body` and `dsh-model-priority`

### Bug Fixes

- A mount refused while the previous holder was still alive is no longer lost: it replays once the holder exits, so the plugin never stays unmounted

### Other Changes

- README: showcase the three most-liked Workshop community plugins
- AGENTS.md: record how index registrations are reviewed and merged
