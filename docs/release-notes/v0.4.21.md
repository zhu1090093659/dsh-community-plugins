社区插件索引随 dsh-web 家族对齐到统一版本 0.4.21，收录四个新社区插件，并完成一处条目改名。

> **兼容性**：包本体没有破坏性变更；`dsh.engines.dsh`、peer 与 engines 下限、包名、导出面、持久化标识与线协议均未改，0.4.20 可直接升上来，也可直接退回，不需要迁移数据。目录层面有一处条目改名：`dsh-man-031` 已改为 `dsh-man-report`。商店按 `id` / `npm` / `repo` 匹配且没有别名，所以装过旧包的用户升级后该条目会显示为未安装，按 npm 的弃用提示改装 `dsh-man-report` 即可。

### 新功能

- 收录社区插件：`deep-projects`（项目空间）、`dsh-audio-reactive`（音频响应）、`dsh-session-history`（会话历史）、`fanframe`（繁界）。
- `dsh-man-031` 改名为 `dsh-man-report`，商店描述同步到上游当前行为：按金额切换四档情绪语音、人民币与美元各十档常用金额整句播报（共 400 条）、两位小数向上取整；自行估算费用时它每天最多一次读取公开价格表与美元兑人民币汇率，不发送会话数据。

### 其他改动

- 新增 2026-11-22 登记轮的 Agent Note；索引条目由 143 条增至 147 条；版本 0.4.20 对齐到 0.4.21。

The community plugin index aligns to the unified family version 0.4.21, listing four new community plugins and renaming one entry.

> **Compatibility**: no breaking changes in the package itself; the `dsh.engines.dsh` floor, peers, engines, package name, export surface, persisted identifiers and wire protocol are untouched, so upgrading from or rolling back to 0.4.20 needs no data migration. One catalog entry was renamed: `dsh-man-031` is now `dsh-man-report`. The store matches on `id` / `npm` / `repo` and carries no aliases, so users who installed the old package see that entry as not installed after upgrading; installing `dsh-man-report` as the npm deprecation notice says resolves it.

### New features

- New community plugins: `deep-projects`, `dsh-audio-reactive`, `dsh-session-history` and `fanframe`.
- `dsh-man-031` is renamed to `dsh-man-report`, and its store copy now matches the upstream behaviour: the voice switches between four emotion tiers by amount, the ten most common amounts in both CNY and USD play as whole-sentence takes (400 takes in total), rounding is a two-decimal ceiling, and when it has to estimate a cost it fetches a public price table and the USD/CNY rate at most once a day while sending no session data.

### Other changes

- Agent Note for the 2026-11-22 registration round added; the index grows from 143 to 147 entries; version 0.4.20 to 0.4.21.
