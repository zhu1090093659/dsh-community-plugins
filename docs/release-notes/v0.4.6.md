社区插件索引随 dsh-web 家族对齐到统一版本。本版本收录一个社区插件条目，并把 `dsh-plugin-hub` 条目同步到其改名后的上游仓库。

> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。包名 `@linxin666/dsh-client-ui-community-plugins` 与安装方式不变；`community.json` 是工坊商店插件列表与 dsh-market.com 插件清单的唯一数据源。索引条目总数为 132。

### 新功能

- 收录宠物额度气泡 `dsh-pet-quota`，在桌面宠物头顶显示当日 token 用量分档与任务事件气泡，经宠物插件公开的 announce 接口推送

### 其他改动

- 同步 `dsh-plugin-hub` 条目到改名后的上游仓库 `dsh-plugin-gating-hub`：更新仓库地址、条目标题与双语描述，改以框架升级安全、升级门控与回滚为核心能力
- Agent Note：记录 2026-10-05 注册轮次的后半程与 2026-10-06 注册轮次
- 说明：`#18`、`#19`、`#20` 三条注册仍因需要变基而保持开启，本版本不包含它们

The community plugin index publishes on the family's aligned version. This release registers one community plugin entry and syncs the `dsh-plugin-hub` entry with its renamed upstream repository.

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field or profile format was renamed. The package name `@linxin666/dsh-client-ui-community-plugins` and its install path are unchanged; `community.json` remains the single data source for the Workshop store plugin list and the dsh-market.com plugin manifest. The index holds 132 entries.

### New Features

- Register the Pet Quota Bubble plugin `dsh-pet-quota`, which shows the day's token usage tier above the desktop pet plus task-event bubbles pushed through the pet plugin's public announce API

### Other Changes

- Sync the `dsh-plugin-hub` entry with its renamed upstream repository `dsh-plugin-gating-hub`: update the repository URL, entry title and bilingual descriptions, and recast it around framework-upgrade safety, upgrade gating and rollback
- Agent Notes: record the second half of the 2026-10-05 registration round and the 2026-10-06 registration round
- Note: the `#18`, `#19` and `#20` registrations stay open pending a rebase and are not part of this release
